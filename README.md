# Alaa Hani - Portfolio

Static website (no build step). Files:
- index.html : the whole site
- assets/portrait.jpg : your photo (replace with a new one using the same name)

## Upload to GitHub Pages
1. Create a new repository on GitHub (e.g. alaa-portfolio), set it to Public.
2. Click "Add file" > "Upload files", drag index.html and the assets folder, then Commit.
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute the site is live at https://YOUR-USERNAME.github.io/alaa-portfolio/

## Edit projects
Open index.html and find "EDIT PROJECTS HERE": change title (t), category (c: dental / reels / ads), Google Drive file id (f) and description (d). The first 3 projects appear in the carousel.
Videos must be shared on Google Drive as "Anyone with the link".
